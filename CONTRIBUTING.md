# Contributing Guidelines

First, thank you for contributing! We aim for high-quality, scientifically sound changes.

## Setup

1. Fork and clone the repository.
2. Ensure you have Python and Node installed.
3. Check `README.md` for specific command setup.

## Testing

Run the test suite before submitting any PR:

```
pytest
```

## Commit Style

Please use [Conventional Commits](https://www.conventionalcommits.org/). For example: `feat:`, `fix:`, `docs:`, `refactor:`, `chore:`, `test:`.

## Honesty Rule

**CRITICAL**: Honesty is the product. No metric without a reproducible script. Do not invent results, metrics, or claim "live" features if they are simulated. All simulated behaviors must be explicitly documented as such.
